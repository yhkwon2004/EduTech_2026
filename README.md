# 골목배움 — 우리 동네 장사왕

**동네 가게들과 매일 겨루는 장사 게임** + 일하는 틈틈이 **3분 사업 교육** + **오늘 할 일**.
골목 상권 소상공인(음식점·카페·소매·미용·서비스)을 위한 모바일 우선 PWA입니다.

## 장사 게임 (메인)

| | |
| --- | --- |
| **창업** | 시·도 → 구 → 동네 선택, 가게 이름·간판·업종, **판매 항목 자유 설정**(이름·원가·판매가·동네 평균가·상품/서비스·당일폐기 여부, 최대 5개) |
| **하루 장사** (하루 1번, 개업 첫 3일은 연속) | 아침 브리핑(날씨·요일·어제 결과·동네 소식) → **상황 카드**(재료값 급등·악성 리뷰·위생 점검·축제 등 15종, 고른 결과와 배울 점) → **생산** 수량 → **가격** → **홍보**(하루 3가지) → 영업 애니메이션 |
| **결산** | 손님·매출·재료비·홍보비·인건비·임대료·폐기, 품절/꽉 참으로 놓친 손님, 리뷰, 리뷰 답글 미니게임, 원인별 조언 + 관련 레슨 |
| **경쟁·랭킹** | 동네 가게 7곳(가격 공세형·장인형·홍보왕·성실형·SNS 핫플형)이 같은 동네 손님을 나눠 가짐. 내가 1~2위면 견제가 심해짐. 골목 점수 = 이익 40·평판 25·손님 점유 20·성장 15 (상대 평가) |
| **시즌·리그** | 7일 시즌, TOP 3는 승급: 동네 골목 리그 → 구 상권 리그 → 시·도 최고 상인 리그. 1위는 칭호('망원동 최고 사장님' … '서울 최고 소상공인'), 명예의 전당 |
| **사업 성장 로드맵** | 1장 창업 준비 → 2장 첫 손님 → 3장 단골 만들기 → 4장 동네 입소문 → 5장 가게 키우기 → 6장 동네 대표 가게 → 7장 지역 최고 소상공인 (장마다 미션·보상) |
| **투자** | 설비(수용량), 알바(수용량·인건비), 인테리어(평판·인지도), 상품별 품질 교육 |
| **배움·실천 연결** | 레슨을 끝낼 때마다 분야별 **노하우 Lv** 상승 → 홍보 효과·원가·고정비·투자 할인 등 게임 효과, 배달앱 광고 해금. 실제 '오늘 할 일'·도전 달성 → **현장 버프**(게임 손님 최대 +15%) |

시뮬레이션은 `src/game/sim.ts`(순수 함수, 시드 고정)에 있고 `src/game/__tests__`에서 회계·재고·가격 탄력·밸런스(잘하면 1주일 안 TOP 3, 무리하면 꼴찌)를 검증합니다.
마이 → 설정의 **체험 모드**를 켜면 하루 제한 없이 연달아 장사해 볼 수 있어요.

### "일하는 틈틈이"를 위한 장치

- **시간대별 오늘 할 일** — 영업시간으로 하루를 6칸으로 나누고 지금 시간대를 먼저 보여 줌. 영업시간 밖 칸은 숨기고 그 칸 할 일은 가까운 칸으로 옮김 (`src/lib/today.ts`, `src/data/routines.ts`)
- **오늘의 도전** — 하루 3개(관심 분야 · 다른 분야 · 1~2분짜리/컨디션), 같은 날은 고정, 최근 7일 한 도전은 제외, "다른 도전"으로 교체 (`src/data/challenges.ts`)

- **시간 기반 추천** — 코스 순서를 지키면서, 이어 하던 코스·관심 분야를 우선으로 N분 안에 끝나는 레슨만 추천 (`src/lib/recommend.ts`)
- **듣기 모드** — 손이 바쁠 때 카드를 소리로 읽고 자동으로 다음 카드로 (브라우저 음성 합성, `src/lib/speech.ts`)
- **틈새 시간 찾기** — 영업시간 안에서 일정 사이 공백을 계산, 일정이 없으면 업종별 한산한 시간대 사용 (`src/lib/schedule.ts`)
- **이어보기** — 카드 위치를 저장해 손님이 와서 끊겨도 그 자리부터
- **하루 뒤 복습 일정** — 레슨을 마치면 내일 틈새 시간에 복습을 바로 넣기
- **오답 복습** — 틀린 퀴즈만 모아 1분 복습
- **큰 글씨 모드**, 한 손 조작(하단 버튼·스와이프), 오프라인 캐시(서비스 워커)

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 로직 단위 테스트 (vitest)
npm run build      # 타입 체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
```

`base: './'` + 해시 라우터라서 `dist/`를 GitHub Pages·Vercel·Netlify 어디에 올려도 그대로 동작합니다. 휴대폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 데이터와 콘텐츠 안내

- 모든 기록은 **기기(localStorage)에만** 저장됩니다. 서버가 없으므로 커뮤니티는 예시 글 + 내가 쓴 글로 동작하는 **미리보기**이며, 앱 안에도 그렇게 표시합니다. 내가 질문을 올리면 "골목 도우미(자동 안내)"가 관련 FAQ·레슨을 연결해 줍니다.
- 세무·노무·지원사업 내용은 **일반적인 안내**입니다. 기준 금액·기한은 바뀔 수 있어 콘텐츠 곳곳에 홈택스(126)·고용노동부(1350)·중소기업통합콜센터(1357) 확인을 안내합니다. 세금 달력은 주말 기한을 다음 월요일로 옮기며 공휴일은 반영하지 않습니다.
