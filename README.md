# 골목 장사왕 — 우리 동네 사업 성장기

레알팜처럼 **마을 지도를 터치해서 캐릭터를 움직이며** 노는 가로형 체험 게임입니다.
텃밭(밭·논)을 일구고, 공방에서 상품을 만들고, 내 가게를 열어 이웃 가게들과 매일 순위를 겨뤄요.
골목상사에 입사해 직무를 골라 일하다가 창업할 수도 있어요. 가는 곳마다 3분 레슨·퀴즈가 연결돼서 **놀다 보면 진짜 장사 노하우가 쌓이는** 구조예요.

## 마을

| 장소 | 하는 일 | 배우는 것 |
| --- | --- | --- |
| 🌱 텃밭 · 🌾 논 | 씨앗 심기 → 물 주기(시간 -40%, 수확 +1) → 수확. 작물 9종, 레벨마다 밭·논 확장 | 직접 키우면 원가가 내려가요 |
| 🛒 도매시장 | 씨앗·재료 사기, 도매 상품 들여오기, 작물 팔기. **시세가 매일 바뀜** | 싼 날 사기, 원가 관리 |
| 🍳 공방 주방 | 레시피대로 재료를 넣어 상품 만들기(실시간 타이머, 작업대 최대 5개) | 레시피 원가·원가율 |
| 🏪 내 가게 | 창업(이름·간판·업종·**판매 항목 자유 설정**: 이름·그림·레시피/도매/서비스·가격) → 진열·가격·상황 카드·홍보 3가지 → 영업 → 결산·리뷰 답글·랭킹. 설비·알바·인테리어·품질 투자 | 수요 예측, 가격, 홍보, 응대 |
| 🏫 골목 배움터 | 9개 코스 27개 3분 레슨(카드 + 퀴즈, 듣기 모드), 오답 복습, 상담 창구(FAQ 검색·사장님 질문방·공공 상담 전화), 노하우 Lv | 세금·노무·마케팅·위생·지원사업 등 |
| 🏢 골목상사 | 6개 직무(마케팅·생산관리·영업·재무회계·인사·고객서비스) 중 골라 입사 → 매일 업무 상황 3개 해결 → 실적·일급 → 인턴~팀장 승진(실적 + 직무 레슨) → 퇴사하고 창업 | 직무별 실전 판단 |
| 🏛️ 창업지원센터 | 지원사업 신청(공고 읽기·서류 퀴즈), 정책자금 대출·상환(매일 이자), 오늘의 영수증 정리(적격증빙 판단) | 지원금 vs 융자, 증빙 |
| 📋 마을 게시판 | 성장 이야기 퀘스트, 오늘의 퀘스트 3개, 리그 랭킹·시상대, 동네 소식, 명예의 전당 | |
| 🏠 이웃 가게 7곳 | 들어가서 관찰(성격·가격·인지도·평판·소식) + "이렇게 이겨 봐요" 전략 | 경쟁 분석 |

- **두 갈래 진로**: 바로 창업(창업 자금 300만 원) 또는 골목상사 입사(월급을 모아 창업). 어느 쪽이든 끝은 지역 최고 소상공인.
- **리그**: 7일 시즌, TOP 3 승급 — 동네 골목 리그 → 구 상권 리그 → 시·도 최고 상인 리그.
- **성장 루프**: 레벨(EXP)·체력(90초마다 1 회복, 레슨을 들으면 회복), 레벨마다 밭·작물·작업대 해금.
- **체험 모드**(설정): 작물·제작 시간 10배 빠르게, 하루 영업·출근 제한 해제.
- 기존 "오늘 할 일·일정" 기능은 빼고, 순수하게 사업을 배우며 성장하는 흐름에 집중했어요.

## 화면·렌더링

- **가로형 전용**: 휴대폰을 세로로 들면 화면 전체를 90° 돌려 가로로 보여 줘요(회전 잠금이어도 옆으로 눕혀 바로 플레이).
- **아이소메트릭 SVG 렌더러**(`src/world/render`): 26×20 타일, A* 길찾기, 탭 이동·드래그 카메라·확대.
  - 땅: 한 장으로 이어진 잔디 + 빛 그라디언트, 돌길·흙길·광장 재질, 길 가장자리 잔디 턱, 물가 거품, 층이 진 섬 절벽, 파도
  - 건물: 기초석·판자/벽돌 외벽·처마 그늘, 액자 창문(유리 반사·밤 불빛), 기와 줄·용마루·박공, 물결 차양, 나무 간판, 굴뚝 연기
  - 캐릭터: 앞/뒤 4방향, 걷기(다리·팔 교차, 고개 흔들림, 그림자), 숨쉬기·눈 깜빡임, 역할별 옷(앞치마/셔츠·넥타이)
  - 공기감: 흘러가는 구름과 그림자, 햇살, 꽃잎, 비네트, 시간대별 색감(아침·노을·밤 가로등)
  - 공용 재질(`Defs.tsx`): 색과 상관없이 덧씌우는 빛·그림자 그라디언트 + 부드러운 그림자 필터

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 단위 테스트 (vitest)
npm run build      # 타입 체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
```

## 데이터와 콘텐츠 안내

- 모든 기록은 **기기(localStorage)에만** 저장됩니다. 서버가 없으므로 사장님 질문방은 예시 글 + 내가 쓴 글로 동작하는 미리보기예요.
- 세무·노무·지원사업 내용은 **일반적인 안내**입니다. 기준은 바뀔 수 있어 홈택스(126)·고용노동부(1350)·중소기업통합콜센터(1357) 확인을 안내합니다.
- 게임 속 지원금·대출은 연습용 가상 금액이에요.
