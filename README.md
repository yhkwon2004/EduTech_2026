# 골목 장사왕 — 우리 동네 사업 성장기

레알팜처럼 **마을 지도를 터치해서 캐릭터를 움직이며** 노는 가로형 체험 게임입니다.
텃밭(밭·논)을 일구고, 공방에서 상품을 만들고, 내 가게를 열어 이웃 가게들과 매일 순위를 겨뤄요.
골목상사에 입사해 직무를 골라 일하다가 창업할 수도 있어요. 가는 곳마다 3분 레슨·퀴즈가 연결돼서 **놀다 보면 진짜 장사 노하우가 쌓이는** 구조예요.

## 마을

| 장소 | 하는 일 | 배우는 것 |
| --- | --- | --- |
| 🌱 텃밭 · 🌾 논 | 씨앗 심기 → 물 주기(시간 -40%, 수확 +1) → 수확. 작물 9종, 레벨마다 밭·논 확장 | 직접 키우면 원가가 내려가요 |
| 🛒 도매시장 | 씨앗·재료 사기, 도매 상품 들여오기, 작물 팔기. **시세가 매일 바뀜** | 싼 날 사기, 원가 관리 |
| 🍳 공방 주방 | 레시피대로 재료를 넣어 상품 만들기(실시간 타이머, 작업대 최대 5개) | 레시피 원가·원가율 |

| 🏢 골목상사 | 6개 직무(마케팅·생산관리·영업·재무회계·인사·고객서비스) 중 골라 입사 → 매일 업무 상황 3개 해결 → 실적·일급 → 인턴~팀장 승진(실적 + 직무 레슨) → 퇴사하고 창업 | 직무별 실전 판단 |
| 🏛️ 창업지원센터 | 지원사업 신청(공고 읽기·서류 퀴즈), 정책자금 대출·상환(매일 이자), 오늘의 영수증 정리(적격증빙 판단) | 지원금 vs 융자, 증빙 |

## 지어 가며 배우는 마을

처음엔 게시판·배움터·배움 나무·빈 가게·골목상사만 있고, 나머지는 **빈 터**예요. 레슨을 듣고 돈을 모아 하나씩 지어요 (클래시 오브 클랜·레알팜의 건설 흐름).

| 건물 | 먼저 깰 스테이지 | 비용 · 공사 시간 |
| --- | --- | --- |
| 🛒 도매시장 | 원가 레슨 1 (팔 값에서 남는 돈 보기) | 5,000원 · 1분 |
| 🍳 공방 주방 | 원가 레슨 2 (효자 메뉴 찾기) · Lv.2 | 10,000원 · 3분 |
| 🏛️ 창업지원센터 | 지원사업 레슨 1 · Lv.3 | 20,000원 · 5분 |

- 빈 터를 누르면 **설계도 창**: 필요한 레슨(바로 배우러 가기)·레벨·돈 체크리스트 → 짓기 시작
- 공사 중엔 비계·먼지·망치질하는 일꾼과 남은 시간이 보이고, 끝나면 🎀 리본 → 완공 연출(꽃가루)
- 체험 모드(설정)에서는 공사도 10배 빨라요

## 배움을 게임처럼

- **스테이지 지도**: 챕터(코스)마다 스테이지 3개가 길로 이어져 있고, 앞 스테이지를 깨야 다음이 열려요. 지금 할 곳엔 내 캐릭터가 서 있어요.
- **스테이지 진행**: 카드(체크리스트는 톡톡 체크) → 퀴즈 3문제(레슨 문제가 모자라면 같은 챕터 보너스 문제). 하트 3개, 연속 정답은 콤보. 옆에서 도트 캐릭터가 응원하고 정답엔 환호해요.
- **결과**: 정답 수만큼 별이 하나씩 터지며 떠오르고, 첫 클리어 코인·3별 보너스·콤보 보너스 EXP, 지식 카드 획득.
- **보물상자**: 챕터를 다 깨면 상자를 열어 모자·안경·머리색 꾸미기를 받아요(꾸미기에서 🔒로 보이던 아이템).
- **지식 카드 도감**: 27장, 아직 못 모은 카드는 실루엣. 3별 카드는 반짝여요.
- **동네 OX 퀴즈**: 마을 사람이 가끔 머리 위에 ❓를 띄우고 멈춰 서요. 다가가면 배운 내용으로 OX 퀴즈(하루 5번).

## 힐링 연출

- **소리**(파일 없이 Web Audio로 합성, `src/world/audio.ts`): 톡·코인·정답 차임·콤보·레벨업·별·책장·수확·발소리… / 오르골 + 패드 배경음악(매번 조금씩 달라져요), 낮엔 새소리, 밤엔 풀벌레. 설정에서 따로 켜고 꺼요.
- **화면 이펙트**(`src/world/fx.tsx`): 반짝이 터짐, 떠오르는 +코인/+EXP, 꽃가루, 물결 고리 — 세로로 돌린 화면에서도 정확한 자리에.
- **마을**: 발걸음 흙먼지, 걸어갈 길 점 표시와 도착 표시, 꽃밭 나비, 하늘의 새 떼, 물 위 반짝임, 건물 탭하면 통통, 밤엔 창문 불빛·가로등 빛 웅덩이·반딧불·별.
- **UI**: 패널 열고 닫기 모션, 아이콘 토스트, 코인 숫자가 굴러 올라가는 카운터, 타이틀 화면 마을 사람 행진.

- **두 갈래 진로**: 바로 창업(창업 자금 300만 원) 또는 골목상사 입사(월급을 모아 창업). 어느 쪽이든 끝은 지역 최고 소상공인.
- **리그**: 7일 시즌, TOP 3 승급 — 동네 골목 리그 → 구 상권 리그 → 시·도 최고 상인 리그.
- **성장 루프**: 레벨(EXP)·체력(90초마다 1 회복, 레슨을 들으면 회복), 레벨마다 밭·작물·작업대 해금.
- **체험 모드**(설정): 작물·제작 시간 10배 빠르게, 하루 영업·출근 제한 해제.
- 기존 "오늘 할 일·일정" 기능은 빼고, 순수하게 사업을 배우며 성장하는 흐름에 집중했어요.

## 화면·렌더링

- **가로형 전용**: 휴대폰을 세로로 들면 화면 전체를 90° 돌려 가로로 보여 줘요(회전 잠금이어도 옆으로 눕혀 바로 플레이). 돌린 화면에서 글자를 쓸 땐 바로 선 입력창이 떠요.
- **카메라**: 드래그 이동, 두 손가락 핀치·마우스 휠·+/- 버튼으로 확대/축소. 카메라는 CSS transform으로 GPU에서 합성돼 끊김이 적어요.
- **아이소메트릭 SVG 렌더러**(`src/world/render`): 26×20 타일, A* 길찾기, 탭 이동·드래그 카메라·확대.
  - 땅: 한 장으로 이어진 잔디 + 빛 그라디언트, 돌길·흙길·광장 재질, 길 가장자리 잔디 턱, 물가 거품, 층이 진 섬 절벽, 파도
  - 건물: 기초석·판자/벽돌 외벽·처마 그늘, 액자 창문(유리 반사·밤 불빛), 기와 줄·용마루·박공, 물결 차양, 나무 간판, 굴뚝 연기
  - 캐릭터: **손으로 찍은 도트(픽셀아트) 치비** — 큰 머리·반짝이는 큰 눈·컬러 외곽선·5단 명암
    - 원화는 `tools/sprite_art.py`에서 부위별로 한 칸씩 찍어요 (얼굴·눈 9종·입 10종·머리카락 8종 앞/뒤·모자 5종·안경 3종·상의 4종·앞치마/넥타이·하의 3종·팔 10포즈·다리 6프레임). `python3 tools/sprite_art.py export`로 `src/world/render/spriteData.ts`를 만들고, 게임(`render/sprite.ts`)은 고른 색으로 팔레트(밝게/기본/그늘/깊은그늘/선, 그늘은 보랏빛)만 바꿔 겹쳐 그려요
    - 앞 3/4 · 뒤 3/4 원화를 좌우로 뒤집어 네 방향, 걷기 4프레임·대기(숨쉬기·눈 깜빡임)·인사·환호·작업·기지개·하품·끄덕임·말하기를 프레임 스트립 + CSS `steps()`로 재생
    - 가만히 있으면 카메라 쪽으로 돌아보고 가끔 두리번·기지개, 체력이 바닥나면 하품. 수확·제작·레슨·승진·영업 결과에 따라 환호/작업/끄덕임
    - 마을 사람 7명(할머니·대리·학생·셰프·카페 알바·농부·라이더)이 걸어 다니다 멈춰서 말풍선으로 혼잣말, 내 캐릭터가 가까이 오면 손 흔들어 인사
  - **내 캐릭터**(왼쪽 위 프로필): 머리 8 · 머리색 8 · 피부 6 · 눈 5 · 눈동자 색 7 · 눈썹 3 · 입 4 · 볼터치 · 모자 6 · 안경 4 · 상의 4 · 하의 3 · 옷/신발 색, 360° 미리보기(끌어서 돌리기, 동작 재생), 🎲 랜덤
  - **캐릭터 시트**: 정면~뒷모습 턴어라운드, 표정 5, 포즈 5, 컬러 팔레트, 디자인 노트 → PNG로 저장 · **마을 사람들 캐스트 시트**도 PNG 저장
  - 공기감: 흘러가는 구름과 그림자, 햇살, 꽃잎, 비네트, 시간대별 색감(아침·노을·밤 가로등)
  - 공용 재질(`Defs.tsx`): 색과 상관없이 덧씌우는 빛·그림자 그라디언트 + 부드러운 그림자 필터

## 데이터와 콘텐츠 안내

- 모든 기록은 **기기(localStorage)에만** 저장됩니다. 서버가 없으므로 사장님 질문방은 예시 글 + 내가 쓴 글로 동작하는 미리보기예요.
- 세무·노무·지원사업 내용은 **일반적인 안내**입니다. 기준은 바뀔 수 있어 홈택스(126)·고용노동부(1350)·중소기업통합콜센터(1357) 확인을 안내합니다.
- 게임 속 지원금·대출은 연습용 가상 금액이에요.
